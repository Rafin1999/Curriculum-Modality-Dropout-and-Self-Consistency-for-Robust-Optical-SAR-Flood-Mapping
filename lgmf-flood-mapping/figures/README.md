# figures/

## Included in this repo

- `fig1_arch.{pdf,svg,png}` - combined method figure: (a) model architecture,
  (b) self-consistency training. Generated by `scripts/draw_fig_arch.py`.
- `fig1a_model.{pdf,svg,png}` - standalone architecture panel.
- `fig1c_consistency.{pdf,svg,png}` - standalone self-consistency panel.

## Not yet included - generate from Kaggle before publishing

These are produced by `notebooks/11_final_results.ipynb` and
`notebooks/12_paper_figures.ipynb` and were saved to each notebook's
`/kaggle/working/figs` output. Copy them here from your saved Kaggle notebook
outputs:

| File | Produced by | Content |
|---|---|---|
| `degradation.pdf` | `11_final_results.ipynb` | Test IoU vs. modality availability, all models |
| `pareto.pdf` | `11_final_results.ipynb` | Test IoU vs. parameter count |
| `fig_qualitative.pdf` | `12_paper_figures.ipynb` | Prediction grids across regimes, ours vs. no-curriculum baseline |
| `fig_dataset.pdf` | `12_paper_figures.ipynb` | S1/S2/label overview across regions |
| `fig_curriculum.pdf` | `12_paper_figures.ipynb` | Exact curriculum schedule (also reproducible via `scripts/plot_curriculum.py`) |
| `fig_failure.pdf` | `12_paper_figures.ipynb` | Worst-performing SAR-only test chips |

`scripts/plot_curriculum.py` can regenerate `fig_curriculum.pdf` standalone
(no need to rerun the full notebook) - see that script's docstring.
